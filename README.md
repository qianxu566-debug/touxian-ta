# 偷闲獭 · 番茄小说检索与排行榜

在线访问：[https://qianxu566-debug.github.io/touxian-ta/](https://qianxu566-debug.github.io/touxian-ta/)（免登录，支持手机与电脑端免 VPN 直接访问）

## 核心机制
- **水线截断深扫** (`scripts/discover.mjs`)：覆盖番茄男女频全部官方主分类（含连载/完结分片）及 74 分类榜 + 巅峰/黑马/热搜/推荐四榜，跌破 8,000 在读水线自动止停，确保 1 万以上在读高覆盖。
- **每日全库实测** (`scripts/observe.mjs`)：每天北京时间 06:00 并发记录全库在读人数、实时总字数、官方标签与 24 小时国内 CDN 直链封面，自动累积 1 天 / 7 天 / 30 天走势和单日日更字数。
- **12 小时封面续命** (`refresh-12h.yml`)：每天北京时间 18:00 仅续期即将过期的国内 CDN 封面直链，不膨胀 Git 历史，实现免 VPN 约 99% 封面秒开。
- **紧凑趋势编译** (`scripts/prepare.py`)：构建时自动打包同源 `data/trends.json.gz`，零外部代理依赖，跨零点自动回退最新有效基准日。
